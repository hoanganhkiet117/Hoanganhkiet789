# HOANG ANH KIET — Tài Xỉu 3D Demo

Bản này là game mô phỏng bằng ĐIỂM ẢO, không có nạp/rút tiền thật.

## File
- index.html
- style.css
- script.js

## Chạy thử
Mở `index.html` trên trình duyệt.

## Đưa lên GitHub Pages
Tạo repository mới -> upload 3 file vào thư mục gốc -> Settings -> Pages -> Deploy from a branch -> chọn `main` và `/ (root)` -> Save.

Trên Android, GitHub có thể upload từng file bằng nút Add file -> Upload files.
